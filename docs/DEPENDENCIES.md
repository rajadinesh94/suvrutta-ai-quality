# Dependency and license inventory

Checked against installed package metadata and the npm registry on 6 October 2026. The repository's authored code is MIT. `@playwright/test`, `playwright`, and `playwright-core` are pinned to 1.57.0 and declare Apache-2.0 in their installed `package.json` files. Optional macOS `fsevents` 2.3.2 declares MIT. Node built-in modules add no package dependency. Browser binaries have separate upstream notices; this inventory is not a legal opinion.

Official primary sources: [Playwright license](https://github.com/microsoft/playwright/blob/main/LICENSE), [Playwright browser install and version matching](https://playwright.dev/docs/browsers), [Playwright CI guidance](https://playwright.dev/docs/ci). The registry's latest version was newer than 1.57.0 at the check date. The pin matches the already cached local browser builds; update it with a fresh browser install and full regression run. The `npm ci` audit on 6 October 2026 reported zero known vulnerabilities in five audited packages; that is time-bound and does not prove absence of vulnerabilities.

The optional Python evaluation dependencies are listed in `scripts/requirements-eval.txt`; installed packages and model weights are not redistributed in this snapshot. The local sanitation helper scans the working tree, ignored artifacts and Git history, reporting only path and finding type. It excludes installed `node_modules`; dependency contents are covered by the lockfile/license review rather than treated as authored export material. Binary media requires manual visual inspection before sharing.
